# Security Policy

## Reporting

Report suspected vulnerabilities through GitHub Private Vulnerability Reporting for this repository. Include the affected version or commit, impact, reproduction steps and supporting evidence.

Do not disclose an unresolved vulnerability in a public issue.

## Scope

Reports may cover the migration interface, wallet connection flow, build pipeline, migration-status service and discrepancies between the documented and deployed Cronos contracts.

Contract vulnerabilities should reference the canonical source and address registry in [xitcoin-org/contracts](https://github.com/xitcoin-org/contracts).

## Disclosure

Please allow time for investigation, remediation and coordinated disclosure. Response time depends on severity and reproducibility.
